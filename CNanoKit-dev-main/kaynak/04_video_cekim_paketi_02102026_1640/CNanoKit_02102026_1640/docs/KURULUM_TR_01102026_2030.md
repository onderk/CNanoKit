# CNanoKit 0.9 — Kurulum ve Kullanım Kılavuzu (Türkçe)

**PIC18F56Q71 Curiosity Nano** kitini **Positron8** derleyicisiyle kullanın: derleyin, programlayın ve USB üzerinden programınızla konuşun.

- Üç IDE'den **biri** yeter: **Positron Studio**, **Proton IDE** ya da **VS Code + Positron eklentisi**.
- MPLAB X IDE / IPE gerekmez. Kitte **hiçbir kablo** gerekmez.
- Ücretsizdir ve garanti yoktur; destek verme yükümlülüğü yoktur. okmn, 2026.
- English: `INSTALL_EN_01102026_2030.md`

> **⚠ Henüz doğrulanmadı.** Bu paket Windows 11 **Pro** + MPLAB X kurulu bir PC'de test edildi. Aşağıdaki iki durum henüz denenmedi; beklenen sonuç bölüm 7'de, kanıtlarıyla birlikte yazılı:
> 1. **Windows 11 Home** üzerinde kurulum.
> 2. **MPLAB X hiç kurulmamış, temiz bir Windows**'ta kitin COM portunun kendiliğinden gelmesi.
>
> Bu durumlardan birinde denerseniz sonucu paylaşmanız herkese yardımcı olur.

## 3. Kurulum sırası (yapmanız gerekenler)

> Her adımda ne görmeniz gerektiği yazılı. Görmüyorsanız bölüm 10'a bakın.

1. **Python'u kurun.** python.org → Downloads → Windows → "Windows installer (64-bit)". İlk ekranda **"Add python.exe to PATH"** işaretleyin → "Install Now".
   - Kısa yol: 6. adımda `CNanoProg_Setup.bat -InstallPython` komutu Python'u winget ile kurar.
   - *Görmeniz gereken:* yeni bir komut penceresinde `python --version` yazınca `Python 3.x.x` çıkar.
2. **Positron derleyicisini ve seçtiğiniz IDE'yi kurun** (protoncompiler.com, kendi kurulum programlarıyla).
   - VS Code kullanacaksanız: code.visualstudio.com → kurun. Sonra Eklentiler (Ctrl+Shift+X) → **"Positron"** (yayıncı *atomix*) → Install.
   - *Görmeniz gereken:* IDE'de bir `.bas` derlenir ve yanında `.hex` oluşur.
3. **Zip'in engelini kaldırın, sonra paketi kalıcı bir yere açın.**
   - Zip → sağ tık → **Özellikler** → alttaki **"Engellemeyi kaldır"** kutusunu işaretleyin → Tamam. Ardından **`C:\CNanoKit`** klasörüne açın (kısa ve boşluksuz yol en güvenlisi).
   - İlk açılışta "Windows bilgisayarınızı korudu" (SmartScreen) çıkarsa: **Ek bilgi → Yine de çalıştır**. Programlar imzasız olduğu için bu normaldir.
   - Kurulum, IDE'lere bu klasörün yolunu yazar. Klasörü sonra taşırsanız kurulumu yeniden çalıştırın.
4. **Bütün IDE'leri kapatın.** IDE'ler kapanırken ayarlarını yeniden yazar.
5. **Kiti USB'ye takın** (kablo takılı olmasın). Windows sürücüleri kendisi kurar.
   - *Görmeniz gereken:*
     - Dosya Gezgini'nde **CURIOSITY** sürücüsü.
     - Aygıt Yöneticisi → Bağlantı noktaları altında **"Curiosity Virtual COM Port (COMx)"** ya da **"USB Seri Cihaz (COMx)"**.
     - Kitte yanan güç LED'i.
6. **`CNanoProg_Setup.bat` dosyasına çift tıklayın.**
   - Pencere 7 adımı geçer. Satır başları: **OK** = zaten tamam, **YAPILDI** = şimdi yapıldı, **!!** = sizin bir şey yapmanız gerek (yanında yazar). En sonda **HEPSİ TAMAM** görmelisiniz.
   - "PositronStudio.ini yazılamadı" derse: sağ tık → **Yönetici olarak çalıştır**.
   - "pymcuprog kuruldu ama PATH'te değil" derse: pencereyi kapatıp bir kez daha çalıştırın.
   - "… açık - kapatın" derse: o IDE'yi kapatıp bir kez daha çalıştırın.
7. **Kontrol:** `CNanoProg_Setup.bat -Check` hiçbir şeyi değiştirmeden durumu raporlar.
8. **İlk deneme:** `examples\CNANO_HELLO_56Q71.bas` dosyasını IDE'nizde açın ve programlayın (bölüm 5). Sonra **CNano Monitor**'ü açın (masaüstü kısayolu), **Bağlan**'a basın.
   - *Görmeniz gereken:* LED0 yarım saniyede bir yanıp söner; monitörde `Hello/Merhaba 0 … 9` satırları akar.
   - Yazıp gönderdiğiniz metin geri gelir (yankı). **SW0**'a basınca `SW0` satırı görünür.

**SW0 denemesi ne işe yarar?** SW0, kitin üzerindeki küçük düğmedir (RA0). Örnek program ona basıldığını monitöre yazar. Bu deneme isteğe bağlıdır; yalnız düğme girişinin (RA0, iç pull-up) çalıştığını gösterir. Zorunlu değildir.

**Dil:** Windows Türkçe ise her şey Türkçe açılır. İngilizce için `CNanoProg_Setup.bat -Lang en` kullanın. Monitörde Dil kutusundan anında değişir.

## 5. Günlük kullanım — üç IDE

Kit takılı olsun. Program, `Device =` satırındaki PIC ile kitteki PIC'i karşılaştırır; farklıysa ya da hex bozuksa **hiçbir şey yazmaz**.

### 5.1 Positron Studio
- **F10 = Derle ve Programla.** Programlayıcı olarak "Curiosity Nano (CNanoProg)" seçili gelir; seçili değilse Settings → Programmers listesinden seçin.
- Konsol penceresinde `programlandı ve doğrulandı, … sn - program çalışıyor` yazar. Enter ile kapanır.
- Monitör: **Tools → CNano Monitor**.

### 5.2 Proton IDE
- Araç çubuğundaki **Program (CNanoProg)** düğmesi gerekiyorsa önce derler, sonra programlar. **Monitor (CNanoMonitor)** monitörü açar. İkisi Plugin menüsünde, "Curiosity Nano" grubunda da vardır.
- Proton IDE'nin kendi "Program" düğmesi geliştiricinin Windows 11 PC'sinde harici programlayıcıyı başlatmadı. Bu yüzden eklenti düğmelerini kullanın.
- `CNanoProtonPlugin.exe` dosyasına çift tıklamayın; o yalnız Proton IDE içinden çalışır.

### 5.3 VS Code (Positron eklentisi)
- `.bas` dosyasını açın. Sağ altta **"FBasic"** yazıyorsa tıklayın ve **Positron** seçin.
- `.bas` dosyası açıkken editörün **sağ üst köşesinde** (sekme satırının sağında) üç simge vardır: **Compile** (derle), **Compile and Program** (derle + programla), **Program** (yalnız programla). Fareyi üstüne getirince adları görünür.
- Klavye: **Ctrl+Alt+M** = derle + programla · **Ctrl+Alt+P** = yalnız programla · **Ctrl+Alt+C** = yalnız derle (Positron eklentisinin kendi tuşları).
- Sonuç alttaki **Output** (Çıktı) panelinde görünür.
- **Monitör:** **Ctrl+Alt+N**, ya da menüden **Terminal → Run Task… → CNano Monitor**. (Kurulum bunu VS Code'un kullanıcı görevlerine ekler.)
- Simgeler yalnız dosya **Positron** dilinde açıkken görünür. Kurulum bunun için VS Code ayarına `"files.associations": { "*.bas": "pos" }` ekler. Hâlâ görünmüyorsa sağ alttaki dil kutusuna tıklayıp **Positron** seçin; sonra VS Code'u bir kez kapatıp açın.
- **Ctrl+Alt+P derlemez** (02.10.2026 kanıtı: değişen .bas'ın .hex'i eski kaldı, CNanoProg "hex is older than the .bas" uyardı). Ctrl+Alt+M çalışmazsa önce **Ctrl+Alt+C**, sonra **Ctrl+Alt+P**.

### 5.4 Komut satırı
```
CNanoProg.exe "C:\iş\BLINK.hex" 18F56Q71                 programla + doğrula + reset
CNanoProg.exe "C:\iş\BLINK.hex" 18F56Q71 -Mode dragdrop  CURIOSITY sürücüsüne kopyalayarak
CNanoProg.exe -Mode info       kit, port, paket bilgisi (exe'ye çift tıklayınca da bu çalışır)
CNanoProg.exe -Mode reset      PIC'i resetle
CNanoProg.exe -Mode erase      PIC'i tamamen sil
CNanoProg.exe -Mode read       PIC'i log\ klasörüne .hex olarak oku (yedek)
-Lang tr | en                  dil
```
`pymcuprog` yoksa program kendiliğinden **sürükle-bırak** yöntemine geçer. Bu yöntem yalnız Windows ister, ama doğrulaması sınırlıdır.

## 6. CNano Monitor (seri monitör)

**Açılınca kendiliğinden bağlanmaz.** Kitin portu listede önceden seçili gelir; bağlantıyı siz başlatırsınız:

1. **Port** — kitin portu listede "Curiosity …" adıyla en üstte, seçili gelir. Kit sonradan takıldıysa **Portları tara**'ya basın.
2. **Hız (baud)** — listeden seçin ya da kutuya yazın (1200 … 500000, kitin USB-seri köprüsünün sınırı: DS50003481A §3.1.2.3). Programınızdaki hızla aynı olmalı.
3. **Veri biti / Eşlik / Dur biti** — çoğu program için 8 / Yok / 1. Kit yalnız 8 veri bitini destekler; eşlik Yok/Tek/Çift, dur biti 1 ya da 2 olabilir.
4. **DTR açık** — **işaretli kalmalı.** Kit, DTR açık olmadıkça veri geçirmez (DS50003481A §3.1.2.4). RTS kit için gerekmez.
5. **Bağlan** — bağlanınca ayarlar kilitlenir ve veri akmaya başlar. **Bağlantıyı kes** ile durur; ayarlar yeniden değiştirilebilir.

| Özellik | Açıklama |
|---|---|
| **Gelen veri: Metin / HEX / Metin + HEX** | Metin: yazdırılamayan baytlar `<1B>` gibi gösterilir. HEX: her bayt `48 65 6C`. Metin + HEX: her satırın altında baytları. |
| **Gönderme biçimi: Metin / HEX baytlar** | Metin: yazdığınızı + seçtiğiniz satır sonunu (Yok/CR/LF/CR+LF) gönderir. HEX: `55 AA 0D 0A`, `0x55,0xAA` ya da `55AA0D0A` biçimlerini kabul eder; satır sonu eklemez. |
| Zaman damgası, Temizle, Kaydet… | Her oturum ayrıca `log\monitor_*.txt` dosyasına kaydedilir. |
| **PIC'i resetle** | Programı baştan başlatır (hata ayıklayıcı üzerinden; seri porta dokunmaz). |
| **Hızlı gönder (4 düğme)** | Tıkla = gönder. Hazır değerler: `okmn`, `HEX:53`, `come`, `stop`. **Shift + tıkla** = düğmeyi değiştir; `HEX:` ile başlarsa HEX bayt gönderir. |
| PIC sürekli veri gönderirken | Gönderme her an çalışır: alttaki kutuya yazıp **Enter** ya da **Gönder**. |
| Alınan / Gönderilen | Bayt sayaçları, durum çubuğunda. |

**Kendi programınızda:** UART2'yi RB4 (TX) / RB5 (RX) pinlerine PPS ile bağlayın. Örnek için `examples\CNANO_HELLO_56Q71.bas`: `RB4PPS = PPS_Fn_TX2`, `U2RXPPS = %00001101`.

Programlama seri portu kullanmaz, monitör açık kalabilir. (Beklenen davranış; uzun süreli eşzamanlı kullanım ayrıca denenmedi.)

## 7. Sürücüler ve "MPLAB X gerekli mi?"

**Kısa cevap: Hayır.**

Geliştiricinin PC'sinde (Windows 11 Pro, MPLAB X kurulu) kit takılıyken görülenler:

| Kitin USB parçası | Kullanılan sürücü | Kim kurdu |
|---|---|---|
| Hata ayıklayıcı (CMSIS-DAP, HID) — programlama bununla | Windows'un kendi HID sürücüsü | **Windows** |
| CURIOSITY sürücüsü (yığın depolama) | Windows'un kendi USB depolama sürücüsü | **Windows** |
| Sanal COM portu (CDC) — monitör bununla | Bu PC'de Microchip `atmel_debuggers_cdc.inf` (usbser.sys kullanır) | **MPLAB X kurulumu** |
| "Curiosity Data Gateway" | Microchip WinUSB | MPLAB X kurulumu — **gerekmez** |

- **Kanıt:** Microchip kit kılavuzu DS50003481A §3.1.2.2: *"Eski Windows sistemlerinde CDC bir USB sürücüsü gerektirir; MPLAB X IDE kurulumu bu sürücüyü içerir."*
- Windows 10/11'in yerleşik `usbser.sys` sürücüsü standart USB-CDC aygıtlarını tanır. Bu yüzden MPLAB X olmayan bir Windows 10/11'de COM portunun "USB Seri Cihaz (COMx)" adıyla gelmesi **beklenir**.
- **⚠ Bu, temiz bir PC'de henüz denenmedi.**
- **COM portu çıkmazsa (yedek):** MPLAB X IDE'yi yalnız sürücüsü için kurun; IDE'yi açmanız gerekmez. Monitör portu hem "Curiosity" adından hem de USB kimliğinden (VID 03EB, PID 2175) tanır.

## 8. Python hakkında

- **Neden gerekli?** Microchip'in resmî, ücretsiz programlama aracı **pymcuprog** Python ile çalışır. Kitin hata ayıklayıcısıyla konuşur: sil, yaz, doğrula, reset. Microchip'in açıklaması: "Curiosity Nano kitlerine takılı PIC aygıtlarını" destekler.
- **Hangi sürüm?** Python **3.14.7 (64 bit)** ile denendi. 3.12, 3.13 ve 3.14 önerilir.
- **Python olmadan?** Çalışır ama sınırlı: sürükle-bırak yöntemi kullanılır; tam doğrulama, silme, okuma ve reset yoktur. Monitör Python istemez.

## 9. (İsteğe bağlı) Jon Walker'ın FREELOADER önyükleyicisi

**Önce bilin:** CNanoKit'in JonW'nin çalışmasıyla **bir bağı yoktur**. Pakette onun hiçbir dosyası ya da kodu yoktur; FREELOADER'ı ne içerir ne değiştirir. Bu bölüm yalnız, isteyen kullanıcının onun ücretsiz aracını bu kitle nasıl deneyebileceğini anlatır. FREELOADER'ı protoncompiler.com forumundaki konusundan, **yazarının lisans koşullarıyla** indirin.

**Bootloader bu kitte gerekli mi?** Hayır. Kitin kendi programlayıcısı 2 saniyede programlar. Bootloader, üzerinde programlayıcı bulunmayan, yalnız seri portu olan **kendi kartınız** için anlamlıdır. Bu kit, onu denemek için iyi bir tezgâhtır.

**Durum (01.10.2026):**
- JonW'nin PIC18F56Q71 için hazırladığı önyükleyici gerçek kitte doğru çalıştı: bağlantı, bilgi okuma, yazma, doğrulama, çıkış ve yeniden giriş.
- Ama **FREELOADER.exe 1.1, kitin USB-COM portunu DTR kapalı açıyor**. Kit DTR kapalıyken veri geçirmediği için (bölüm 6) yükleme zaman aşımına düşüyor. Bu durum yazarına bildirildi. Yani **bugün FREELOADER bu kitin USB portu üzerinden kullanılamıyor.**

**Neden iki kablo?** JonW'nin önyükleyicisi **UART1'i RC6 (TX) / RC7 (RX)** pinlerinde kullanıyor; kitin USB-seri hattı ise RB4/RB5'e bağlı. İki kablo bu iki pin çiftini birleştirir. Resimler: `docs\Kablo_Baglanti_TR_01102026_2150.png` (TR) ve `docs\Wiring_FREELOADER_EN_01102026_2150.png` (EN).
- Kablo 1: **RC6 → RB4** — sol sıra 13. delik → sol sıra 25. delik.
- Kablo 2: **RB5 → RC7** — sol sıra 26. delik → sağ sıra 28. (en alt) delik.
- Delikler USB konnektörü üstteyken yukarıdan sayılır. Kabloları kit USB'ye takılı değilken takın.
- Kablolar takılıyken uygulamanız **RC7'yi asla çıkış yapmamalı** (RC7 = LED0, kablo ile kitin CDC TX hattına bağlıdır) ve RC6'yı giriş bırakmalıdır. Örnek programlar (HELLO, KOMUT) RB5–RC7 kablosunu ilk gelen baytta kendileri algılar ve o durumda RC7'yi hiç sürmez. İşiniz bitince kabloları çıkarın.
- Kitin USB hattını doğrudan kullanan (UART2 = RB4/RB5) bir önyükleyici sürümü olsaydı kablo hiç gerekmezdi. Bu, yazarına yalnız bir öneri olarak iletildi.

**FREELOADER DTR'yi açık tutan bir sürüm çıkarsa, kullanım sırası:**
1. Önyükleyiciyi bir kez kitin kendi programlayıcısıyla yazın: `CNanoProg.exe P56Q71_MWBOOT.hex 18F56Q71`.
2. Kendi programınızı **normal** derleyin; koda bootloader eklemezsiniz. FREELOADER uygulamanın başlangıcını kendisi yerleştirir.
   - Yazarının notlarına göre: uygulamanın yapılandırma (config) satırları önyükleyicininkiyle uyumlu olmalı ve program önyükleyicinin alanına (belleğin en üst kısmı) taşmamalı. Ayrıntılar FREELOADER'ın kendi belgelerindedir.
3. Yükleyin: `CNanoProg.exe <uygulama.hex> 18F56Q71 -Mode freeloader`. Kitin hata ayıklayıcısı reset atar; düğmeye gerek yoktur.
- **Dikkat:** Sonra kiti CNanoProg ile normal programlarsanız (F10 / Ctrl+Alt+M), çip silinir ve **önyükleyici de silinir**. Yeniden denemek için 1. adımı tekrarlayın.

## 10. Sorun giderme

| Belirti | Neden / Çözüm |
|---|---|
| "Kit bulunamadı" | Kablo yalnız şarj kablosu olabilir; veri kablosu deneyin. CURIOSITY sürücüsü görünüyor mu? Başka bir USB portu deneyin. |
| Kitteki PIC ile programın PIC'i farklı uyarısı | `.bas` içindeki `Device =` kitle aynı olmalı (`18F56Q71`). Bu bir güvenlik kontrolüdür. |
| "Hex .bas'tan eski" uyarısı | Önce derleyin. Proton eklentisi bunu kendisi yapar. |
| `CNanoProtonPlugin.exe` "tek başına çalışmaz" diyor | Doğru: çift tıklanmış. Proton IDE içindeki **Program (CNanoProg)** düğmesini kullanın. |
| Monitörde veri yok | Bağlan'a bastınız mı? DTR işaretli mi? Baud ve format programınızla aynı mı? Programınız UART2 RB4/RB5 kullanıyor mu? RB4/RB5'e kablo takılı mı? |
| COM portu yok | Bölüm 7, yedek çözüm. |
| "Port açılamadı" | Başka bir terminal açık (Tera Term, MPLAB Data Visualizer, ikinci bir monitör). Kapatın. |
| Positron Studio F10 bir şey yapmıyor | Settings → Programmers'da "Curiosity Nano (CNanoProg)" seçili mi? Kurulumu IDE kapalıyken yeniden çalıştırın. |
| VS Code "programmer not set" | VS Code açıkken kurulum yapılmış. VS Code'u kapatıp kurulumu tekrar çalıştırın. |
| Proton IDE'de düğmeler yok | Proton IDE'yi kapatın, `CNanoProg_Setup.bat -Steps protonide` çalıştırın, Proton IDE'yi açın. |
| Kayıtlar | `log\`: `Setup_*.log`, `CNanoProg_*.log`, `monitor_*.txt` |

## 11. Yedekleme, format sonrası, yeni PC

1. **Yedekleyin:** `C:\CNanoKit` klasörünün tamamı ve kendi `.bas` projeleriniz.
2. **Yeni Windows'ta** bölüm 3'ü aynı sırayla yapın: Python → Positron + IDE → klasör → IDE'leri kapat → kiti tak → `CNanoProg_Setup.bat`.
3. Kurulumu defalarca çalıştırmak zararsızdır; yapılmış adımlar için **OK** der.

## 12. Kaldırma

- Kısayolları silin (Masaüstü ve Başlat menüsü\CNanoKit).
- `%APPDATA%\PDS\Plugin\CNano` klasörünü silin.
- Positron Studio: Settings → Programmers'dan satırı kaldırın ya da `log\` içindeki ini yedeğini geri koyun.
- VS Code: `settings.json` içindeki `pos.main.programmer` satırlarını silin.
- İsterseniz `pip uninstall pymcuprog`. Son olarak `C:\CNanoKit` klasörünü silin.
