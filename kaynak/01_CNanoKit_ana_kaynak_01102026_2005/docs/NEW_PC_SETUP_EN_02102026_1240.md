# Setting up CNanoKit on a new PC — in order (Windows 11 Pro)

Versions are the ones we tested (October 2026). Newer ones will probably work but are not tested.

## A. First (once)
1. Finish **Windows Update**, restart.
2. **Positron8 compiler** (paid licence, RosettaMicro): main installer + latest corrections update → tested **4.0.6.4**. Proton IDE (**2.0.3.3**) comes with it.
3. Pick an IDE (one is enough):
   - **Positron Studio 2.1.0.4** (free, John Barrat), or
   - **Proton IDE 2.0.3.3** (came with step 2), or
   - **VS Code 1.140** + extension **"Positron" by atomix 2.9.0**.
4. **Python 3.14.7, 64-bit** (python.org). Tick **"Add python.exe to PATH"** on the first screen.

## B. CNanoKit
5. Download the zip. **Before unzipping:** right-click → Properties → **Unblock** → OK.
6. Unzip to `C:\CNanoKit`.
7. Close all IDEs. Double-click **`CNanoProg_Setup.bat`** (internet, once):
   - installs Microchip **pymcuprog** (tested 3.19.4.61);
   - downloads the Microchip **PIC18F-Q_DFP** device pack (~40 MB, tested 1.31.492);
   - adds buttons / shortcuts to the installed IDEs.
   No red lines at the end.

## C. Kit
8. Plug the kit in with a **data** USB cable (Micro-B). No driver to install.
   - a **CURIOSITY** drive appears,
   - Device Manager → **Ports** shows **"Curiosity Virtual COM Port (COMx)"**.
9. **Not needed:** wires, jumpers, a bootloader, MPLAB X.

## D. First run
10. Open `C:\CNanoKit\examples\CNANO_HELLO_56Q71.bas`.
11. Compile + program:
    - Positron Studio: **F10** · Proton IDE: **CNano Program** button · VS Code: **Ctrl+Alt+M** (if it does nothing: **Ctrl+Alt+C**, then **Ctrl+Alt+P**).
12. Open the monitor (VS Code: **Ctrl+Alt+N**) → **Connect** → "Hello/Merhaba" lines.
13. Optional external LED: **RD0 → 1 kΩ → LED → GND**.

## Good to know
- In VS Code **Ctrl+Alt+P only programs, it does not compile.** If the `.bas` changed, compile first, or the old `.hex` is written (warning "hex is older than the .bas").
- Programming erases the whole chip; a bootloader in the chip is erased too.
